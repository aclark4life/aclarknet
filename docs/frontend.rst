README
======

This project was created with
`python-webpack-boilerplate <https://github.com/AccordBox/python-webpack-boilerplate>`__

Available Scripts
-----------------

In the project directory, you can run:

``npm run start``
~~~~~~~~~~~~~~~~~

``npm run start`` launches a server process with live reloading.

If you change JS or SCSS files, the page refreshes automatically. The
server uses port 9091 by default; change it in
``webpack/webpack.config.dev.js``.

``npm run watch``
~~~~~~~~~~~~~~~~~

Run webpack in ``watch`` mode.

``npm run build``
~~~~~~~~~~~~~~~~~

In `production mode <https://webpack.js.org/guides/production/>`__,
Webpack focuses on minified bundles, lighter source maps, and optimized
assets to improve load time.
